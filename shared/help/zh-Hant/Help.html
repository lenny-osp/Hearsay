入門

Hearsay 會錄下你的麥克風與通話聲音，並在 Mac 上轉錄。除非你將逐字稿送到 AI 提供者產生會議筆記，否則任何資料都不會離開你的 Mac。需要搭載 Apple 晶片、執行 macOS 14 或以後版本的 Mac。

Hearsay 會錄下你的麥克風與通話聲音，並在 PC 上轉錄。除非你將逐字稿送到 AI 提供者產生會議筆記，否則任何資料都不會離開你的 PC。需要 64 位元的 Windows 10（2004 版或以後版本）或 Windows 11。

  1. 在「設定 > 輸出」中選擇檔案的儲存位置。預設為「文件」資料夾中的 Hearsay 資料夾（%USERPROFILE%\Documents\Hearsay）。
  2. 打開「模型」標籤頁，然後按一下模型旁的「下載」。建議使用 whisper-large-v3-turbo（1.61 GB）；whisper-large-v3-turbo-4bit（463 MB）是最小且品質不錯的選項。若該模型不是「使用中的模型」，請按一下「使用」。
  3. 打開「模型」標籤頁，然後按一下模型旁的「下載」。建議使用 Whisper Large v3 Turbo (5-bit)（574 MB）。若該模型不是「使用中的模型」，請按一下「使用」。
  4. 按下「開始」（位於「錄音」標籤頁）。macOS 詢問時，請允許取用麥克風及「螢幕與系統錄音」（Hearsay 只使用其中的音訊）。之後可在「系統設定 > 隱私權與安全性」中更改這兩項設定。
  5. 按下「開始」（位於「錄音」標籤頁）。在 Windows 上，錄製系統聲音不需要權限。若麥克風錄不到聲音，請在「設定 > 隱私權與安全性 > 麥克風」中允許桌面應用程式存取麥克風。
  6. 若允許後仍錄不到系統聲音，請結束並重新打開 Hearsay。

錄音

使用「錄音」標籤頁錄製會議並取得逐字稿。

  1. 選擇「麥克風」。保持開啟「同時擷取系統聲音」，即可錄進通話另一方的聲音。
  2. 選擇「語言」：「自動」會自動偵測，也可以選擇 EN、DE 或 ES。ZH-TW 以繁體字輸出中文，ZH-CN 以簡體字輸出。
  3. 按下「開始」。音量表會顯示麥克風與系統聲音是否有收到聲音；靜音 5 秒後會出現警告。「暫停」期間的內容不會列入逐字稿。
  4. 新文字大約每 30 秒會出現在「即時預覽」中。若這台 PC 太慢，標籤頁會顯示即時預覽已關閉，只產生最終逐字稿（請參閱疑難排解）。
  5. 按下「停止」。Hearsay 會再轉錄一次整段錄音，產生最終逐字稿。若要略過此步驟，請按一下「改用即時預覽」。
  6. 若要緊接著錄下一場會議，請改按「結束並開始下一場」（⌃⌥⌘N）。錄好的錄音會在下方「轉錄佇列」中等待並在背景轉錄；在「設定 > 一般」的「轉錄已結束的錄音」可改為等沒有錄音時再轉錄。
  7. 若要緊接著錄下一場會議，請改按「結束並開始下一場」（Ctrl+Alt+Win+N）。錄好的錄音會在下方「轉錄佇列」中等待並在背景轉錄，預設要等沒有錄音時才開始；在「設定 > 一般」的「轉錄已結束的錄音」可改為「立即（背景）」。

逐字稿（SRT）和錄音（WAV）會儲存在輸出資料夾中，並以開始時間命名，例如 2026-09-28_14-05-00.srt。

  • 「自動」最多會聽取前 90 秒的語音。若無法判斷語言，會改用自動模式預設語言並加以提示，同時提供按鈕讓你以其他語言重新轉錄。若你選擇了某種語言，但會議聽起來是另一種語言，橫幅會提供「重新轉錄」。
  • 「自動模式預設語言」可在「設定 > 一般」中設定。「自動」聽到中文時，若自動模式預設語言是简体中文，會以簡體字輸出，否則以繁體字輸出。

轉錄檔案

使用「檔案」標籤頁轉錄現有的音訊或影片檔案。

  1. 將檔案拖放到「檔案」標籤頁，或按一下「選擇…」。Hearsay 可讀取 wav、m4a、mp3、aac、aiff、caf 檔案，以及 mp4 和 mov 檔案中的音訊。Hearsay 可讀取 wav、m4a、mp3、aac、wma、flac 檔案，以及 mp4 和 mov 檔案中的音訊。
  2. 選擇「語言」，方式與「錄音」標籤頁相同。
  3. 若要停止，請按一下「取消」。不會儲存任何內容。

SRT 會儲存在輸出資料夾中，並以檔名中的時間命名；若檔名沒有時間，則使用檔案的日期。原始檔案絕不會被更改。

會議筆記

Hearsay 可將逐字稿送到 AI 提供者，並儲存其撰寫的會議筆記。送出時，整份逐字稿都會分享給該提供者。

  1. 在「設定 > AI」中，於「預設集：」選擇提供者。
    • GitHub Copilot CLI、Claude Code CLI、Codex CLI 和 Antigravity CLI 會使用你 MacPC 上安裝的程式，以及你在其中登入的帳號。請求會計入該訂閱方案的用量限制。各程式的檢查按鈕（例如「檢查 Claude Code」）會顯示是否找到程式及是否已登入。各程式的安裝指令顯示在其預設集下方。
    • 在 Windows 上，Copilot 和 Antigravity 無法處理很長的逐字稿（約 20 分鐘以上的會議）；這類會議請改用 Claude Code、Codex、Ollama 或「自訂」。
    • Ollama / LM Studio 在你的 MacPC 上執行。
    • 「自訂」適用於任何相容 OpenAI 的服務。請輸入其 URL、模型和權杖。
  2. 按一下「測試連線」。你可以在「提示詞範本」下加入自己的筆記指示。
  3. 逐字稿儲存後，Hearsay 會詢問「要送出逐字稿以產生會議筆記嗎？」選擇「範本：」和「筆記語言：」，然後按一下「送出」。「保留在本機」則不會送出任何內容。
  4. 可視需要編輯建議的會議名稱，然後按一下「儲存」。
檔案內容
<timestamp>_<name>.srt附時間的逐字稿
<timestamp>_<name>.md會議筆記
<timestamp>_<name>_transcript.md結構化逐字稿
<timestamp>_<name>.wav錄音

歷史記錄

「歷史記錄」標籤頁會列出輸出資料夾中的會議。使用列上的按鈕，或按住 Control 鍵並按一下該列。或在該列上按一下滑鼠右鍵。

  • 「打開 SRT」、「打開筆記」和「打開逐字稿」會打開檔案；「在 Finder 中顯示」會在 Finder 中顯示檔案。
  • 「打開 SRT」、「打開筆記」和「打開逐字稿」會打開檔案；「在檔案總管中顯示」會在檔案總管中顯示檔案。
  • 「產生筆記…」會為已儲存的逐字稿產生筆記。「重新產生筆記…」會取代現有筆記；新筆記儲存後，舊筆記會移到垃圾桶資源回收筒。
  • 「重新命名…」會重新命名該會議的所有檔案；「丟到垃圾桶…」會將它們全部移到垃圾桶。
  • 「重新命名…」會重新命名該會議的所有檔案；「移至資源回收筒…」會將它們全部移到資源回收筒。

選單列與快速鍵通知區域與快速鍵

不打開視窗也能控制 Hearsay。關閉視窗後，錄音仍會繼續。

  • 「Hearsay 顯示位置：」（位於「設定 > 視窗」）可選擇「選單列與 Dock」、「僅選單列」或「僅 Dock」。
  • 「Hearsay 顯示位置：」（位於「設定 > 視窗」）可選擇「通知區域與工作列」、「僅通知區域」或「僅工作列」。選擇「僅工作列」時，關閉視窗會結束 Hearsay。
  • 按一下通知區域中的 Hearsay 圖示可打開視窗；按一下滑鼠右鍵可查看狀態，並開始、暫停或停止錄音。錄音時圖示會變成紅色，其工具提示會顯示已錄時間；若要維持原樣，請在「設定 > 視窗」關閉「在通知區域顯示錄音狀態」。
  • 按一下選單列圖像可查看狀態，並開始、暫停或停止錄音。錄音時圖像會變成紅色並顯示已錄時間；若要維持原樣，請在「設定 > 視窗」關閉「在選單列顯示錄音狀態」。
  • 在任何 App 中，按下 ⌃⌥⌘R 可開始或停止錄音，按下 ⌃⌥⌘P 可暫停或繼續。若要更改，請前往「設定 > 一般 > 快速鍵」，按一下快速鍵，然後按下新的組合鍵。
  • 在任何 App 中，按下 Ctrl+Alt+Win+R 可開始或停止錄音，按下 Ctrl+Alt+Win+P 可暫停或繼續。快速鍵顯示在「設定 > 一般 > 快速鍵」中；「重置」可還原預設值。
  • 按下 ⌘, 可打開「設定」，按下 ⌘? 可打開此說明。
  • 按下 F1 可打開此說明。

設定與其他

  • 介面語言：可在「設定 > 一般」中選擇。Hearsay 需要重新啟動；請按一下「立即重新啟動」。變更會在 Hearsay 下次啟動時生效。
  • 啟動：在同一處啟用「登入時開啟 Hearsay」。
  • 更新：Hearsay 選單中的「檢查更新…」提供「安裝更新」（下載、驗證並安裝新版本，然後重新啟動 Hearsay）或「在 GitHub 上檢視」（打開版本頁面）。
  • 錄音檔：若要在成功轉錄後刪除 WAV，請關閉「成功轉錄後保留錄音（WAV）」（位於「設定 > 輸出」）。
  • 未完成的錄音：若 Hearsay 或 MacPC 在錄音途中停止，下次開啟時會詢問如何處理。「轉錄」會產生逐字稿，「保留」會將 WAV 移到輸出資料夾，「刪除」則會移除它。

疑難排解

  • 未安裝模型——打開「模型」標籤頁，下載模型，然後按一下「使用」。
  • 沒有麥克風取用權限——在「系統設定 > 隱私權與安全性 > 麥克風」中開啟 Hearsay。
  • 沒有麥克風取用權限——在「設定 > 隱私權與安全性 > 麥克風」中開啟麥克風存取權，以及桌面應用程式的存取權。
  • 系統聲音已關閉——在 Windows 上，錄製系統聲音不需要權限。請確認喇叭或耳機輸出已連接並開啟，然後開始新的錄音。
  • 系統聲音已關閉：權限遭拒——在「系統設定 > 隱私權與安全性 > 螢幕與系統錄音」中開啟 Hearsay，然後開始新的錄音。
  • 允許後仍錄不到系統聲音——結束並重新打開 Hearsay。
  • 更新後系統聲音無法錄製——這個 Hearsay 版本沒有使用 Developer ID 簽署，因此 macOS 會忘記權限。在「錄音」標籤頁按一下「修正…」，然後在「系統設定 > 隱私權與安全性 > 螢幕與系統錄音」中重新開啟 Hearsay。
  • 裝置「沒有音訊」——確認裝置已連接且未靜音，或選擇其他「麥克風」。
  • AirPods 或其他藍牙耳機的音質不佳——錄音時，macOSWindows 會將它們切換為低音質的通話模式。在吵雜的環境中，請使用 MacPC 的內建麥克風。
  • 找不到 AI 程式——安裝該程式，或在「設定 > AI」中輸入其路徑。
  • 找不到 AI 程式——使用「設定 > AI」中該預設集下方顯示的指令安裝（例如 Claude Code 為在 PowerShell 中執行 irm https://claude.ai/install.ps1 | iex），或在該處輸入其路徑。
  • AI 程式尚未登入——在「終端機」終端機中執行一次 copilot、claude、codex login 或 agy，然後在「設定 > AI」中按一下該程式的檢查按鈕。
  • 找不到檔案——資料夾位置顯示在「設定 > 輸出」中。在「歷史記錄」標籤頁中，按一下「在 Finder 中顯示」。
  • 找不到檔案——資料夾位置顯示在「設定 > 輸出」中，預設為 %USERPROFILE%\Documents\Hearsay。在「歷史記錄」標籤頁中，按一下「在檔案總管中顯示」。
  • 轉錄很慢，或即時預覽已關閉——Hearsay 會盡量透過 Vulkan 使用顯示晶片，否則使用處理器（CPU）。使用 CPU 時，最終逐字稿約需錄音長度的 1.5 到 3.5 倍時間，且即時預覽會保持關閉。配備 Intel、AMD 或 NVIDIA 顯示晶片的 PC 會快很多。
