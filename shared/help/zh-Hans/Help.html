入门

Hearsay 会录制你的麦克风和通话声音，并在 Mac 上完成转录。除非你将转录稿发送给 AI 提供方以生成会议笔记，否则任何内容都不会离开你的 Mac。需要配备 Apple 芯片且运行 macOS 14 或更高版本的 Mac。

Hearsay 会录制你的麦克风和通话声音，并在 PC 上完成转录。除非你将转录稿发送给 AI 提供方以生成会议笔记，否则任何内容都不会离开你的 PC。需要 64 位的 Windows 10（2004 版或更高版本）或 Windows 11。

  1. 在设置 > 输出中选择文件的保存位置。默认位置是“文稿文档”文件夹中的 Hearsay 文件夹（%USERPROFILE%\Documents\Hearsay）。
  2. 打开模型标签页，点按模型旁边的下载。推荐使用 whisper-large-v3-turbo（1.61 GB）；whisper-large-v3-turbo-4bit（463 MB）是体积最小的可靠选择。如果该模型不是当前模型，请点按使用。
  3. 打开模型标签页，单击模型旁边的下载。推荐使用 Whisper Large v3 Turbo (5-bit)（574 MB）。如果该模型不是当前模型，请单击使用。
  4. 点按开始（位于录音标签页）。macOS 询问时，请允许访问麦克风以及录屏与系统录音（Hearsay 只使用音频）。之后可以在系统设置 > 隐私与安全性中更改这两项。
  5. 单击开始（位于录音标签页）。在 Windows 上，录制系统声音不需要权限。如果麦克风录不到声音，请在设置 > 隐私和安全性 > 麦克风中允许桌面应用访问麦克风。
  6. 如果允许后仍然录不到系统声音，请退出并重新打开 Hearsay。

录音

使用录音标签页录制会议并获取转录稿。

  1. 选择麦克风。保持打开同时录制系统声音，即可录入通话另一方的声音。
  2. 选择语言：自动会自动检测语言，也可以选择 EN、DE 或 ES。ZH-TW 以繁体字输出中文，ZH-CN 以简体字输出中文。
  3. 点按开始。电平表显示麦克风和系统声音是否收到声音；静音 5 秒后会出现警告。暂停期间的内容不会计入转录稿。
  4. 新文字大约每 30 秒出现在实时预览中。如果这台 PC 太慢，标签页会显示实时预览已关闭，只生成最终转录稿（参见故障排除）。
  5. 点按停止。Hearsay 会再次转录整段录音，生成最终转录稿。如要跳过此步骤，请点按改用实时预览。
  6. 如要紧接着录下一场会议，请改为点按结束并开始下一场（⌃⌥⌘N）。录好的录音会在下方转录队列中等待并在后台转录；在设置 > 通用的转录已结束的录音可改为等没有录音时再转录。
  7. 如要紧接着录下一场会议，请改为点按结束并开始下一场（Ctrl+Alt+Win+N）。录好的录音会在下方转录队列中等待并在后台转录，默认要等没有录音时才开始；在设置 > 通用的转录已结束的录音可改为立即（后台）。

转录稿（SRT）和录音（WAV）保存在输出文件夹中，以开始时间命名，例如 2026-09-28_14-05-00.srt。

  • 自动最多听取开头 90 秒的语音。如果无法判断语言，它会使用自动模式默认语言并给出提示，同时提供一个按钮，用于以其他语言重新转录。如果你选择了某种语言，但会议听起来是另一种语言，横幅会提供重新转录。
  • 自动模式默认语言可在设置 > 通用中设置。自动识别到中文时，如果自动模式默认语言是简体中文，则以简体字输出，否则以繁体字输出。

转录文件

使用文件标签页转录已有的音频或视频文件。

  1. 将文件拖到文件标签页，或点按选取…。Hearsay 可读取 wav、m4a、mp3、aac、aiff、caf，以及 mp4 和 mov 文件中的音频。Hearsay 可读取 wav、m4a、mp3、aac、wma、flac，以及 mp4 和 mov 文件中的音频。
  2. 选择语言，方法与录音标签页相同。
  3. 如要停止，请点按取消。不会保存任何内容。

SRT 保存在输出文件夹中，以文件名中的时间命名；如果文件名中没有时间，则以文件的日期命名。原始文件不会被更改。

会议笔记

Hearsay 可以将转录稿发送给 AI 提供方，并保存其生成的会议笔记。发送时会将整份转录稿共享给该提供方。

  1. 在设置 > AI中，从预设：选择提供方。
    • GitHub Copilot CLI、Claude Code CLI、Codex CLI 和 Antigravity CLI 使用 MacPC 上安装的程序及其中已登录的账户。请求会计入该订阅的用量限制。其检查按钮（例如检查 Claude Code）会显示是否找到该程序以及是否已登录。每个程序的安装命令显示在其预设下方。
    • 在 Windows 上，Copilot 和 Antigravity 无法处理很长的转录稿（约 20 分钟以上的会议）；这类会议请改用 Claude Code、Codex、Ollama 或自定义。
    • Ollama / LM Studio 在你的 MacPC 上运行。
    • 自定义适用于任何兼容 OpenAI 的服务。请输入其 URL、模型和令牌。
  2. 点按测试连接。在提示词模板下，可以为笔记添加你自己的指示。
  3. 保存转录稿后，Hearsay 会询问要发送转录稿以生成会议笔记吗？选择模板：和笔记语言：，然后点按发送。保留在本地则不发送任何内容。
  4. 可以根据需要编辑建议的会议名称，然后点按保存。
文件内容
<timestamp>_<name>.srt带时间码的转录稿
<timestamp>_<name>.md会议笔记
<timestamp>_<name>_transcript.md结构化转录稿
<timestamp>_<name>.wav录音

历史记录

历史记录标签页列出输出文件夹中的会议。可以使用某一行上的按钮，或按住 Control 键点按该行。或右键单击该行。

  • 打开 SRT、打开笔记和打开转录稿用于打开文件；在访达中显示会在访达中显示文件。
  • 打开 SRT、打开笔记和打开转录稿用于打开文件；在文件资源管理器中显示会在文件资源管理器中显示文件。
  • 生成笔记…为已保存的转录稿生成笔记。重新生成笔记…会替换现有笔记；新笔记保存后，旧笔记会移到废纸篓回收站。
  • 重命名…会重命名某个会议的所有文件；移到废纸篓…会将它们全部移到废纸篓。
  • 重命名…会重命名某个会议的所有文件；移到回收站…会将它们全部移到回收站。

菜单栏和快捷键通知区域和快捷键

无需打开窗口也可以控制 Hearsay。关闭窗口后录音会继续进行。

  • 通过Hearsay 显示位置：选择 Hearsay 的显示位置（在设置 > 窗口中）：菜单栏和程序坞、仅菜单栏或仅程序坞。
  • 通过Hearsay 显示位置：选择 Hearsay 的显示位置（在设置 > 窗口中）：通知区域和任务栏、仅通知区域或仅任务栏。选择仅任务栏时，关闭窗口会退出 Hearsay。
  • 单击通知区域中的 Hearsay 图标可打开窗口；右键单击可查看状态，并开始、暂停或停止录音。录音时图标会变成红色，其工具提示会显示已录时间；若要保持不变，请在设置 > 窗口中关闭在通知区域显示录音状态。
  • 点按菜单栏图标可查看状态，并开始、暂停或停止录音。录音时图标会变成红色并显示已录时间；若要保持不变，请在设置 > 窗口中关闭在菜单栏显示录音状态。
  • 在任何应用中，按下 ⌃⌥⌘R 可开始或停止录音，按下 ⌃⌥⌘P 可暂停或继续。如要更改，请前往设置 > 通用 > 快捷键，点按一个快捷键，然后按下新的组合键。
  • 在任何应用中，按下 Ctrl+Alt+Win+R 可开始或停止录音，按下 Ctrl+Alt+Win+P 可暂停或继续。快捷键显示在设置 > 通用 > 快捷键中；重置可恢复默认值。
  • 按下 ⌘, 打开设置，按下 ⌘? 打开本帮助。
  • 按下 F1 打开本帮助。

设置及其他

  • 界面语言：在设置 > 通用中选择。Hearsay 需要重新启动；请点按立即重新启动。更改会在 Hearsay 下次启动时生效。
  • 启动：在同一位置打开登录时打开 Hearsay。
  • 更新：Hearsay 菜单中的检查更新…提供安装更新（下载、验证并安装新版本，然后重新启动 Hearsay）或在 GitHub 上查看（打开版本页面）。
  • 录音：如要在转录成功后删除 WAV，请关闭转录成功后保留录音（WAV）（位于设置 > 输出）。
  • 未完成的录音：如果 Hearsay 或 MacPC 在录音过程中停止运行，下次启动时会询问如何处理该录音。转录会生成转录稿，保留会将 WAV 移到输出文件夹，删除则会将其删除。

故障排除

  • 未安装模型 — 打开模型标签页，下载一个模型，然后点按使用。
  • 没有麦克风访问权限 — 在系统设置 > 隐私与安全性 > 麦克风中打开 Hearsay。
  • 没有麦克风访问权限 — 在设置 > 隐私和安全性 > 麦克风中打开麦克风访问权限，以及桌面应用的访问权限。
  • 系统声音已关闭 — 在 Windows 上，录制系统声音不需要权限。请检查扬声器或耳机输出是否已连接并打开，然后开始新的录音。
  • 系统声音已关闭：权限被拒绝 — 在系统设置 > 隐私与安全性 > 录屏与系统录音中打开 Hearsay，然后开始新的录音。
  • 允许后仍然录不到系统声音 — 退出并重新打开 Hearsay。
  • 更新后系统声音无法录制 — 这个 Hearsay 版本没有使用 Developer ID 签名，因此 macOS 会忘记权限。在录音标签页点按修复…，然后在系统设置 > 隐私与安全性 > 录屏与系统录音中重新打开 Hearsay。
  • 某个设备“没有音频” — 检查设备是否已连接且未静音，或选择其他麦克风。
  • AirPods 或其他蓝牙耳机的音质较差 — 录音时，macOSWindows 会将其切换到低音质的通话模式。在嘈杂的房间里，请使用 MacPC 的内建麦克风。
  • 找不到 AI 程序 — 安装该程序，或在设置 > AI中输入其路径。
  • 找不到 AI 程序 — 使用设置 > AI中该预设下方显示的命令安装（例如 Claude Code 为在 PowerShell 中运行 irm https://claude.ai/install.ps1 | iex），或在该处输入其路径。
  • AI 程序未登录 — 在终端中运行一次 copilot、claude、codex login 或 agy，然后在设置 > AI中点按其检查按钮。
  • 找不到文件 — 文件夹显示在设置 > 输出中。在历史记录标签页中，点按在访达中显示。
  • 找不到文件 — 文件夹显示在设置 > 输出中，默认为 %USERPROFILE%\Documents\Hearsay。在历史记录标签页中，单击在文件资源管理器中显示。
  • 转录很慢，或实时预览已关闭 — Hearsay 会尽量通过 Vulkan 使用显卡芯片，否则使用处理器（CPU）。使用 CPU 时，最终转录稿约需录音时长的 1.5 到 3.5 倍，并且实时预览会保持关闭。配备 Intel、AMD 或 NVIDIA 显卡芯片的 PC 会快很多。
